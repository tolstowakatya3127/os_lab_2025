# Архитектура гибридного хранилища TechData Solutions

## 1. Executive Summary
Для компании TechData Solutions спроектировано трехуровневое гибридное хранилище на базе Docker, MinIO и FUSE. Решение позволяет снизить затраты на хранение (TCO) на 60% за счет автоматического перемещения неиспользуемых данных в дешевые архивы (COLD tier), сохраняя при этом мгновенный доступ к активным проектам (HOT tier).

## 2. Бизнес-требования
* Активные проекты (10%): Время доступа < 10 мс.
* Недавние проекты (30%): Время доступа < 100 мс.
* Архивы (60%): Допустимо восстановление за часы.
* Минимизация стоимости хранения.

## 3. Архитектура решения
* **HOT Tier:** Локальный быстрый SSD (папка `/data/hot`). Используется для активной работы.
* **WARM Tier:** S3-хранилище (MinIO), примонтированное через FUSE (s3fs) в `/data/warm`. Баланс между скоростью и ценой.
* **COLD Tier:** Симуляция глубокого архива (папка `/data/cold`). Используется для данных, к которым нет обращений.

## 4. Политики миграции данных
1. **Demote (Понижение):**
   * Если файл не открывался 7 дней -> переносится из HOT в WARM.
   * Если файл не открывался 30 дней -> переносится из WARM в COLD.
2. **Promote (Продвижение):**
   * При любом обращении (`get`) к файлу на уровне WARM или COLD, он немедленно переносится обратно в HOT.

## 5. Экономический анализ (TCO - Total Cost of Ownership)
* Стоимость хранения 1 ТБ на SSD (HOT): ~$100/мес. (Храним 10% = 50 ТБ -> $5000/мес)
* Стоимость хранения 1 ТБ в S3 (WARM): ~$20/мес. (Храним 30% = 150 ТБ -> $3000/мес)
* Стоимость хранения 1 ТБ в Архиве (COLD): ~$1/мес. (Храним 60% = 300 ТБ -> $300/мес)
* **Итого:** ~$8300/мес. Без гибридной системы (все на SSD) стоило бы $50,000/мес. **Экономия 83%**.

## 6. План внедрения
1. Настройка Docker-инфраструктуры (MinIO + s3fs).
2. Разработка приложения-менеджера (HybridStorageManager).
3. Интеграция cron-задач для вызова `migrate()` раз в сутки.
4. Мониторинг наполнения уровней.
